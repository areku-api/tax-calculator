# โดนกี่บาท — ปีภาษี 2569

ใส่รายได้มา ดูว่าปีนี้ภาษีโดนแถวไหน — เงินเดือน (40(1)) / ฟรีแลนซ์ (40(2))

- คำนวณฝั่ง client ทั้งหมด ไม่ส่งรายได้ขึ้นเซิร์ฟเวอร์
- กฎและตัวเลขอยู่ใน config รายปี (`src/config/taxYear2569.ts`)
- ไม่ใช่การยื่นภาษีจริง — เป็นเครื่องมือวางแผน

## รัน

```bash
npm install
npm run dev
```

## ทดสอบ

```bash
npm test
```

## สร้าง build

```bash
npm run build
```

## เปลี่ยนปีภาษี

คัดลอก `src/config/taxYear2569.ts` เป็นปีใหม่ แก้ตัวเลข แล้วลงทะเบียนใน `src/config/index.ts`
